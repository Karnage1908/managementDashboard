================================================================================
          COMMAND DASHBOARD — GITHUB PAGES DEPLOYMENT GUIDE
================================================================================

This project is a zero-build Single Page Application (SPA) designed to work
immediately on GitHub Pages. Follow the step-by-step instructions below.

--------------------------------------------------------------------------------
PREREQUISITES
--------------------------------------------------------------------------------
1. Git installed on your computer.
2. A GitHub account (https://github.com).

--------------------------------------------------------------------------------
STEP 1: CREATE A NEW REPOSITORY ON GITHUB
--------------------------------------------------------------------------------
1. Go to https://github.com/new
2. Enter a Repository name (e.g., "command-dashboard" or "ai-workshop").
3. Set the repository visibility to Public (or Private if you have GitHub Pro).
4. Do NOT check "Add a README file", ".gitignore", or "license" (we already have them).
5. Click the green "Create repository" button.

--------------------------------------------------------------------------------
STEP 2: INITIALIZE GIT AND PUSH YOUR CODE
--------------------------------------------------------------------------------
Open PowerShell, Command Prompt, or your terminal inside this folder:
(c:\Users\KaRNaGe\Desktop\ai workshop)

Run the following commands one by one:

  git init
  git add .
  git commit -m "Initial commit - Command personal dashboard"
  git branch -M main
  git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
  git push -u origin main

*(Replace <YOUR_GITHUB_USERNAME> and <YOUR_REPO_NAME> with your actual details)*

--------------------------------------------------------------------------------
STEP 3: CONFIGURE GITHUB PAGES (TWO EASY OPTIONS)
--------------------------------------------------------------------------------

OPTION A: USING GITHUB ACTIONS (RECOMMENDED)
-------------------------------------------
The repository already includes an automated workflow:
`.github/workflows/deploy.yml`

1. Open your repository on GitHub.
2. Click on "Settings" (top tab).
3. In the left sidebar, click "Pages" (under Code and automation).
4. Under "Build and deployment" -> "Source", select "GitHub Actions" from the dropdown.
5. That's it! GitHub Actions will automatically deploy the site.

OPTION B: DIRECT BRANCH DEPLOYMENT
----------------------------------
1. Open your repository on GitHub.
2. Click on "Settings" (top tab).
3. In the left sidebar, click "Pages".
4. Under "Build and deployment" -> "Source", keep "Deploy from a branch".
5. Under "Branch", select "main" and folder "/ (root)".
6. Click "Save".

--------------------------------------------------------------------------------
STEP 4: ACCESS YOUR LIVE DASHBOARD
--------------------------------------------------------------------------------
After 1-2 minutes, your dashboard will be live at:

  https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/

--------------------------------------------------------------------------------
FUTURE UPDATES
--------------------------------------------------------------------------------
Whenever you make changes to the code in the future, simply run:

  git add .
  git commit -m "Describe your update"
  git push

GitHub Pages will automatically rebuild and update your live site within minutes!
