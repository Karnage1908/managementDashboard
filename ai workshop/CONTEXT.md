# Product Context

## Product

Personal Academic & Professional Management Dashboard

## User

A student or early-career professional managing academics, career
preparation, projects, skills, goals, applications, and personal
productivity.

## Problem

Important information is normally fragmented across calendars,
spreadsheets, task managers, notes, university systems, job boards,
GitHub, cloud storage, and messaging platforms.

This fragmentation makes it difficult to answer:

-   What needs attention now?
-   Which deadlines are approaching?
-   Am I progressing toward my goals?
-   Which skills am I missing?
-   Which projects demonstrate those skills?
-   Which career opportunities need follow-up?
-   Am I overcommitted?
-   What did I accomplish over the last month?

## Product Vision

Create a personal command center that connects execution with long-term
development.

The product should turn disconnected activity into a coherent
development graph:

`Vision → Goals → Areas → Projects → Tasks → Evidence → Outcomes`

## Key Differentiator

The dashboard should connect activity to outcomes.

Example:

`Career Goal → Target Role → Required Skill → Project → Task → Evidence → Portfolio → Application`

## MVP Philosophy

The MVP should be useful without integrations or AI.

Manual data entry must be fast and reliable. Integrations and
intelligent recommendations should be layered on later.
